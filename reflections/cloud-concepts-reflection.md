Every day, I use different cloud services without realizing how important they are in my daily life. Three of the services I use regularly are Google Drive, Facebook Messenger, and Canva. They help me store files, communicate with others, and complete my school requirements more efficiently.

*Google Drive* is an example of *Software as a Service (SaaS)* because it allows me to save, access, and share my files through a web browser without installing or managing the software myself. Its deployment model is *Public Cloud* because it is available to millions of users over the internet.

*Facebook Messenger* is also a *Software as a Service (SaaS)*. It lets me send messages, make voice and video calls, and share files online. It uses the *Public Cloud* because anyone with a Facebook account can use the service through the internet.

*Canva* is another *Software as a Service (SaaS)* application. I use it to create presentations, posters, and other school projects. It is also classified as *Public Cloud* since users can access their designs from different devices using an internet connection.

Learning about Git and GitHub helped me understand why version control is important in cloud computing projects. When several people work on the same project, Git records every change, making it easy to review previous versions or restore files if something goes wrong. GitHub also allows team members to collaborate, track updates, and manage project files in one place. This helps reduce errors and keeps everyone working on the latest version of the project.

Overall, this lesson made me realize that cloud computing is already part of my everyday life. Many of the applications I use depend on cloud technology, and GitHub is an important tool for keeping cloud-based projects organized and collaborative.

Client Recommendations

Client A – Startup Company

Recommended Cloud Platform: Amazon Web Services (AWS)

AWS is a suitable choice for a startup with a limited budget because it offers flexible and scalable cloud services. The startup can begin with the resources it needs and scale them as the mobile application gains more users. AWS also provides many services that can support application development, storage, databases, and monitoring. This flexibility can help the company manage its costs while preparing for rapid growth.

Recommended Services:

- Amazon EC2 – Compute resources for running application servers.
- Amazon S3 – Storage for application files and other data.
- Amazon RDS – Managed relational database service.
- Amazon CloudWatch – Monitoring and observability for applications and resources.

---

Client B – University

Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is the most appropriate choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, which can make migration and identity management easier. The university can gradually move selected services to the cloud while continuing to use its existing Microsoft environment. This can also reduce the complexity of managing a mixed on-premises and cloud infrastructure.

Recommended Services:

- Azure Virtual Machines – Hosting Windows Server and Linux workloads.
- Microsoft Entra ID – Cloud-based identity and access management.
- Azure SQL Database – Managed relational database service.
- Azure Virtual Network – Networking for cloud resources.

---

Client C – AI Research Company

Recommended Cloud Platform: Google Cloud Platform (GCP)

Google Cloud is a strong choice for an AI research company because it provides services designed for artificial intelligence, machine learning, and high-performance workloads. The company can use Google's specialized infrastructure and AI/ML tools to develop and train models. Google Cloud also provides scalable computing resources that can be adjusted according to research requirements. These capabilities make it suitable for demanding AI and machine learning applications.

Recommended Services:

- Compute Engine – Scalable virtual machines for high-performance workloads.
- Google Kubernetes Engine (GKE) – Running and managing containerized AI applications.
- Vertex AI – Developing, training, and deploying machine learning models.
- Cloud Storage – Storing datasets, models, and other research files.

---

Client D – Global E-Commerce Company

Recommended Cloud Platform: Amazon Web Services (AWS)

AWS is a strong choice for a global e-commerce company because it provides scalable and highly available infrastructure for applications serving users around the world. Its global infrastructure and services can help distribute workloads and handle changes in traffic. The company can automatically scale computing resources during periods of high demand and reduce resources when demand decreases. This makes AWS suitable for supporting a large online shopping platform.

Recommended Services:

- Amazon EC2 – Running application and web servers.
- Elastic Load Balancing – Distributing traffic across application resources.
- Amazon RDS – Managing the e-commerce database.
- Amazon CloudFront – Delivering web content to users globally.
- AWS Auto Scaling – Automatically adjusting resources based on demand.

- ## Checkpoint 6 – Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | AWS offers a wide range of scalable services that can support a startup as it grows. |
| Enterprise Organization | AWS | AWS provides a broad range of services and enterprise capabilities for different workloads and business requirements. |
| Microsoft Environment | Microsoft Azure | Azure provides strong integration with Windows Server, Microsoft 365, and Microsoft Entra ID. |
| AI / Machine Learning | Google Cloud | Google Cloud provides strong AI and machine learning services, including Vertex AI and scalable computing resources. |
| Kubernetes Deployment | Google Cloud | Google Kubernetes Engine (GKE) provides a managed Kubernetes environment for deploying and managing containerized applications. |
| Global Web Application | AWS | AWS provides global infrastructure, scalable compute resources, load balancing, and content delivery services for applications serving users worldwide. |
